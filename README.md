# SportSee

## Description

This project was developed as part of the OpenClassrooms Web Developer program.
SportSee is an analytics dashboard for sports coaching, featuring interactive charts and data visualization.

## Project Goals

-   Create an analytics dashboard using React
-   Implement data visualization with Recharts
-   Handle API data fetching and integration

## Technical Features

-   React Implementation:
    -   Vite build tool
    -   Custom PropTypes validators
    -   Component documentation (JSDoc)
    -   API service abstraction
-   Data Visualization:
    -   Activity tracking charts
    -   Performance analytics
    -   Score visualization
    -   Custom data formatting
-   API Integration:
    -   HTTP request handling
    -   Data transformation
    -   Mock data support
